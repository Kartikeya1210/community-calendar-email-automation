# Provenance and naming

Recovered code: the existing personal Community Calendar & Email Automation repository and local recovered service. It contains calendar reminder rendering, email validation/MIME, Gmail integration, Cloud Tasks scheduling and Firestore state.

The task “SGI Raleigh Chapter Calendar and Emails” records that the old district workflow was shut down and its source recovered for a public portfolio repository. The user then described an entire chapter comprising four districts as a **new project**. Consequently, this repository is evidence of the earlier district reminder service, not evidence of a completed chapter-wide calendar builder.

New in this reconstruction (2026-09-25): credential-free fictional email preview, validation/MIME tests, this provenance record and README limitations. The source files under `src/` are recovered rather than newly rewritten. No real calendar, member list, addresses, credentials or production data were copied.

Not implemented here: PDF/Word calendar parsing, district-wide calendar selection, audience tagging UI, Word calendar layout, or automatic derivation of reminders three/one days before events. The service accepts a coordinator-prepared campaign and explicit delivery timestamps.
