# Security and privacy

This repository is intentionally a public, sanitised implementation reference.

Do not commit contact lists, personally identifying information, home addresses, OAuth client secrets, refresh tokens, API tokens, generated calendars, or production cloud identifiers. Keep operational secrets in a managed secret store and give runtime identities only the permissions they need.

If you discover a security issue in this example, please open a private report through the repository owner's preferred contact channel rather than publishing credential-like data in an issue.
