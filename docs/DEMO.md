# Demo guide

1. Run `npm run demo` from the repository.
2. Open `demo-output/reminder.html` and show the fictional event, time, audience and neutral signature.
3. Open the `.eml` as text to show plain-text and HTML alternatives. Do not send it.
4. Run `npm test` and explain why header and audience/recipient validation matter.
5. Walk through the README diagram: reviewed campaign, queue, durable state and Gmail.
